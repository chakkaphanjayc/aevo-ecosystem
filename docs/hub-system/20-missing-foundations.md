# Missing Foundations

## P0 — blocks safe migration

- Canonical ownership ledger for every shared table and writer.
- Contract release that matches actual Core Hub routes.
- Fail-closed entitlement evaluation outside local development.
- Cross-tenant and RLS transaction-context integration suite.
- Versioned app compatibility handshake.
- Clean origin/route inventory with removed `:4321` and `/modern/organize` references resolved.

## P1 — blocks complete Hub control plane

- Core-owned installation and location-binding projection.
- Manifest-backed app catalog and feature schema.
- Complete invitation/member/assignment lifecycle.
- Billing webhook-to-entitlement projection evidence.
- Typed app configuration APIs and ownership boundaries.
- Idempotent store template/duplicate provisioning events.

## P2 — required for operational maturity

- Worker event consumer with retry/dead-letter behavior.
- Hub dashboard read models and freshness indicators.
- Device pairing/attestation/offline policy.
- Cloudflare rate/WAF and origin enforcement evidence.
- Full runbooks for migration, restore, session revocation, and entitlement incident response.

## P3 — intentionally deferred

- Generic plugin runtime.
- Remote executable UI/plugin loading.
- Warehouse-wide cross-app analytics before event ownership is stable.
- Broad redesign of app domain databases that is not needed for Hub boundary correctness.
